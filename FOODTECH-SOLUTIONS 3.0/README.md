# 🍕 FoodTech Solutions - Sistema de Gestión para Restaurantes

Sistema integral para la gestión de restaurantes que incluye control de mesas, pedidos, facturación, inventario y reportes.

## 🚀 Características

- **Gestión de Mesas**: Control de estado y asignación en tiempo real
- **Sistema de Pedidos**: Toma de pedidos y seguimiento hasta la facturación
- **Facturación**: Generación de facturas con múltiples métodos de pago
- **Inventario**: Control de stock y alertas de productos bajos
- **Reportes**: Analytics y métricas del negocio
- **Multi-rol**: Sistema de permisos para diferentes tipos de usuario

## 🛠 Tecnologías

### Backend
- Java 17 + Spring Boot 3.2
- Spring Security con JWT
- JPA/Hibernate + MySQL 8.0
- Maven

### Frontend
- HTML5, CSS3, JavaScript ES6+
- Arquitectura modular sin frameworks
- Web Components nativos
- API REST
